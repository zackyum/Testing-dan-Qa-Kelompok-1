
# Referensi Standar ISO

## Pendahuluan

Pengujian website Mutoh2000 mengacu pada standar ISO/IEC/IEEE 29119 dan ISO/IEC 25010:2023. Standar tersebut digunakan sebagai dasar dalam menentukan tahapan pengujian, penyusunan dokumentasi, teknik pengujian, dan penilaian kualitas website.

- Objek Pengujian: Mutoh2000
- URL: https://mutoh2000.com/
- Metode: Black Box Testing

| No. | Standar | Pembahasan | Referensi |
| :--- | :--- | :--- | :--- |
| 1 | ISO/IEC/IEEE 29119-1:2022 | Konsep dasar dan terminologi software testing. | [ISO 29119-1](https://www.iso.org/standard/81291.html) |
| 2 | ISO/IEC/IEEE 29119-2:2021 | Proses pengujian mulai dari perencanaan, pelaksanaan, hingga penyelesaian. | [ISO 29119-2](https://www.iso.org/standard/79428.html) |

| 5 | ISO/IEC 25010:2023 | Model dan karakteristik kualitas perangkat lunak. | [ISO 25010](https://www.iso.org/standard/78176.html) |

## 2. Penerapan Standar

Penerapan ISO/IEC/IEEE 29119 pada pengujian website Mutoh2000 meliputi:

- Penyusunan Test Plan.
- Penyusunan Test Scenario dan Test Case.
- Pelaksanaan Manual dan Automated Testing.
- Pencatatan defect yang ditemukan.
- Penyusunan laporan hasil pengujian.

Teknik Black Box Testing yang digunakan antara lain Equivalence Partitioning, Boundary Value Analysis, dan Error Guessing.

## 3. Karakteristik Kualitas ISO/IEC 25010:2023

| Karakteristik | Fokus Pengujian |
| :--- | :--- |
| Functional Suitability | Kesesuaian fungsi pencarian, filter, kategori, dan detail produk. |
| Performance Efficiency | Waktu pemuatan halaman dan respons website. |
| Compatibility | Interaksi dengan layanan eksternal yang tersedia. |
| Interaction Capability | Kemudahan penggunaan dan navigasi website. |
| Reliability | Konsistensi fungsi dan penanganan kesalahan. |
| Security | Pemeriksaan dasar keamanan website melalui HTTPS. |
| Flexibility | Responsivitas dan adaptasi pada berbagai perangkat dan browser. |
| Maintainability | Tidak diuji karena keterbatasan akses kode sumber. |
| Safety | Tidak menjadi fokus pengujian pada studi kasus ini. |

## 5. Kesimpulan

ISO/IEC/IEEE 29119 digunakan sebagai acuan proses dan dokumentasi pengujian, sedangkan ISO/IEC 25010:2023 digunakan sebagai dasar penilaian kualitas website Mutoh2000.

Penerapan standar disesuaikan dengan ruang lingkup pengujian dan keterbatasan akses terhadap website.
