# Test Scenario - Mutoh2000

## 1. Tujuan

Test Scenario disusun berdasarkan hasil identifikasi fitur website Mutoh2000 dan ruang lingkup yang telah ditentukan dalam Test Plan.

Setiap skenario akan dikembangkan menjadi test case positif dan negatif menggunakan metode Black Box Testing.
